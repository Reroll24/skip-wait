# v0.12.2-beta.1

早期预览版，可能有 bug，欢迎反馈。

## 本版改动

- 尝试修复：登录后走到舰桥时，加速没有及时结束、之后还能加速移动的问题
- 收工判据改为按本场视角的相对比例，不再受游戏内 FOV 设置影响；上限改按游戏秒计算

相比 0.12.1，还包含：设置菜单支持中文 / English 实时切换。

## 目前支持

- 登录进船、冷冻舱、FTL / 队伍外景、空降舱进出、空投发射的舰桥推进、任务结算、回船电梯
- 鹈鹕起飞（仅单人）
- 每段独立倍速，可跳过的段另有「跳过」开关

## 安装

- 管理器：导入 `skip_wait-addon-0.12.2-beta.1.zip`，启用并 Deploy
- 本地：解压 `skip_wait-0.12.2-beta.1.zip`，把 `skip_wait` 放进 `%LOCALAPPDATA%\MDL\Helldivers2\Mods\`
- 二选一，不要同时装；需要 MDL3 3.0.0-dev.33 或更新

## 反馈

- Issue：https://github.com/Reroll24/skip-wait/issues
- 附日志：`%LOCALAPPDATA%\MDL\Helldivers2\Logs\` 下的 `SkipWait.log`，或 `MDL.log` 里 `[skipwait]` 开头的行
- 「详细日志」默认开启，保持开启即可

## English

A beta fix for the login speed-up that kept running after reaching the bridge. Camera checks are now relative to the scene's own widest view, and caps are counted in game seconds.

Supports login, cryo, FTL / squad exterior, hellpod entry and exit, drop-launch bridge push-in, mission debrief and the return elevator, plus solo Pelican takeoff — per-segment speed, and a skip toggle where it makes sense.

Install with the manager addon or as a local mod folder — never both. Requires MDL3 3.0.0-dev.33 or newer.

Report problems with the `[skipwait]` log lines on GitHub Issues: https://github.com/Reroll24/skip-wait/issues
