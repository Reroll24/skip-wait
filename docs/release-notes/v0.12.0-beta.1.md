# v0.12.0-beta.1 — first public beta

**Skip Wait / 跳过人生** 是适配 MDL3 的《绝地潜兵 2》过场跳过 mod，为每段过场提供独立的倍速与「跳过」开关。这是第一个公开测试版。

**Skip Wait / 跳过人生** is an MDL3 cutscene-skip mod for *Helldivers 2*: a separate speed and skip toggle for every segment. This is the first public beta.

> ⚠️ **早期预览版 / early preview**：各方面仍在优化，可能有 bug，有问题请带日志反馈（`%LOCALAPPDATA%\MDL\Helldivers2\Logs\` 下的 `SkipWait.log`，或 `MDL.log` 里 `[skipwait]` 开头的行；「详细日志」默认已开启）。英文为翻译内容，可能不准确。
> Everything can still be improved and bugs are likely. When reporting, include the log (see above). The English text is a translation and may be imprecise.

## 安装 / Install

二选一，不要同时装。
Pick one route — not both.

- **管理器 / Manager**: 导入 `skip_wait-addon-0.12.0-beta.1.zip`（Arsenal / HD2MM），启用并 Deploy。
  Import `skip_wait-addon-0.12.0-beta.1.zip`, enable, Deploy.
- **本地 mod / Local mod**: 解压 `skip_wait-0.12.0-beta.1.zip`，把 `skip_wait/` 放进 `%LOCALAPPDATA%\MDL\Helldivers2\Mods\`。
  Unzip `skip_wait-0.12.0-beta.1.zip` and put `skip_wait/` into `%LOCALAPPDATA%\MDL\Helldivers2\Mods\`.

设置 / Settings: ESC → MOD 设置 / Mod Options → **Skip Wait / 跳过人生**（6 节 18 项 / 6 sections, 18 options）。

运行环境 / Runtime: **MDL3 3.0.0-dev.33**（Lua 5.1）。Bingus Shared Loader 自 2026-10-20 更新后失效，不再支持。
**MDL3 3.0.0-dev.33** (Lua 5.1). Bingus Shared Loader has been broken since the 2026-10-20 update and is not supported.

## 已知限制 / Known limitations

- 跳过功能目前还在测试阶段，出问题请带 `MDL.log` 的 `[skipwait]` 段落反馈。
